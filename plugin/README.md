# Remote LLM Gateway

Чат в боковой панели Explorer. Проект остаётся на вашей машине: в начале сессии файлы уходят на шлюз, после ответа правки записываются обратно в редактор.

Локальные `grok` и `claude` плагин не запускает. Модель, лимит и прокси задаются в админке шлюза.

## Настройки

| Настройка | Что делает |
|---|---|
| `remoteLlm.gatewayUrl` | Адрес шлюза, `http` или `ws` |
| `remoteLlm.gatewayToken` | Токен пользователя из админки |
| `remoteLlm.useRemoteGateway` | Подключаться к шлюзу |

Команда «Remote LLM: показать назначенную модель» показывает модель и расход.
