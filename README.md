# Remote LLM Gateway

Открытый проект **Remote LLM Gateway** — централизованный шлюз, который позволяет использовать мощные LLM-агенты (Grok Build, Claude Code, GPT и другие) через один сервер.

Поддерживает:
- VS Code плагин **Remote LLM Gateway**
- CLI-утилиту `remote-llm` (аналог `grok` / `claude`)
- Веб-админку с управлением пользователями, токенами, моделями и аналитикой (запросы + расход токенов)

## Основная идея

Все пользователи подключаются к одному публичному шлюзу. Плагин и CLI работают с **локальным проектом** на компьютере пользователя, но весь интеллект, инструменты, MCP и выполнение кода происходят на сервере.

Монорепозиторий содержит:
- `cmd/remote-llm/` — CLI-утилита `remote-llm` (TUI)
- `gateway/` — основной LLM Gateway (WebSocket + ACP)
- `admin/` — маленькая веб-админка
- `api/` — доработанный LLM API с поддержкой пользовательских токенов
- `plugin/` — **Remote LLM Gateway** (VS Code плагин)

Смотрите полный план в [`ARCHITECTURE.md`](ARCHITECTURE.md).
