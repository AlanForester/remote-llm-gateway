## Продукт

- [ ] **Исходящий прокси для backend-агентов.** Запросы на выходе из Claude Code, Grok Build и остальных агентов идут через прокси. Адрес прокси задаётся двумя способами, и смена любого из них меняет прокси:
  - в веб-админке;
  - переменной в `.env`.
  Шлюз применяет значение к процессам агентов (их исходящие вызовы API провайдеров).
- [ ] **Принудительная LLM для пользователя.** В веб-админке пользователю можно принудительно назначить LLM. Плагин и CLI отображают эту назначенную модель.
- [ ] **Лимиты использования.** В админке у пользователя задаются лимит токенов и период сброса. Шлюз считает токены периода и не пускает новые запросы после лимита, пока период не сбросится.
